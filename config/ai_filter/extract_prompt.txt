Règles d'extraction :
1. Chaque tag est concis (2 à 6 caractères), accompagné d'une phrase de description précisant les sujets et mots-clés que ce tag couvre
2. Les tags doivent se chevaucher le moins possible entre eux
3. Maîtrise le nombre de tags entre 5 et 20 ; privilégie la conservation des tags fins et ne fusionne que lorsque le sens se recoupe fortement
4. La description doit être concrète et inclure des mots-clés précis (noms de personnes, de sociétés, de produits, etc.) pour faciliter la classification ultérieure
5. L'ordre de retour doit respecter autant que possible l'ordre d'apparition dans la description des intérêts de l'utilisateur : plus un tag est en tête, plus sa priorité est élevée
