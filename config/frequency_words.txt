# Éditeur visuel : docs/index.html (bilingue FR/EN)
#
# Toute ligne commençant par # est un commentaire (lecture seule).
#
# Ce fichier définit les mots-clés à surveiller. Le système remonte les actualités
# (flux RSS) contenant ces mots-clés. Adapté ici au marché HALAL, avec des termes en
# français, en anglais et en translittération arabe courante.
#
# Deux sections :
#   [GLOBAL_FILTER]  - Filtre global : exclut les contenus non désirés
#   [WORD_GROUPS]    - Groupes de mots : ce que l'on veut suivre
#
# ───────────────────────────────────────────────────────────────
#                       Aide-mémoire syntaxe
# ───────────────────────────────────────────────────────────────
#   mot                un mot-clé simple ; le titre le contenant correspond
#   /regex/            expression régulière (ajouter /i pour ignorer la casse)
#   mot => alias       attribue un nom d'affichage à un mot-clé
#   [Nom du groupe]    première ligne d'un groupe : nom affiché de tout le groupe
#   +mot               mot obligatoire (tous les « + » doivent correspondre)
#   !mot               mot d'exclusion (exclut l'actu si présent — dans ce groupe)
#   @nombre            limite le nombre d'actus affichées pour ce groupe
#
# Les groupes sont séparés par une ligne vide. Dans un groupe, les mots sont en « OU ».
# Astuce anglais : /\bmot\b/i évite les correspondances partielles et ignore la casse.
# ───────────────────────────────────────────────────────────────


# ───────────────────────────────────────────────────────────────

# ───────────────────────────────────────────────────────────────
